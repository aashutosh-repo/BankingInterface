# 🏦 BankingInterface

A modular Angular-based banking interface demonstrating various banking instruments like customer onboarding, loan management, SIP calculators, data visualizations, and more.

---

## 🚀 Features

- 🔐 Secure Login Page
- 🏠 Dynamic Home Dashboard
- 👥 Customer Onboarding Form
- 📊 Interactive Charts for Data Analysis
- 📈 SIP Calculator with Visual Summary
- 💰 EMI (Loan) Calculator
- 💳 Payments & Transaction Interface *(Work in Progress)*

---

## 🛠️ Tech Stack

- **Frontend:** Angular, TypeScript, SCSS, HTML
- **Charting Library:** [ng2-charts](https://valor-software.com/ng2-charts/)
- **Design System:** Custom SCSS with responsive layout
