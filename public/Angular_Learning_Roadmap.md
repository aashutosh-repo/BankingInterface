# 🅰️ Angular Learning Path

A structured roadmap to become proficient in Angular — from beginner concepts to enterprise-grade development.

---

## 📘 Phase 1: Foundations (Week 1–2)

### 🎯 Goal:
Understand Angular fundamentals, components, data binding, and basic forms.

### ✅ Topics:
- Angular CLI & Project Setup
- Components: Inputs, Outputs, Events
- Data Binding (Interpolation, Property, Event, Two-way)
- Directives: *ngIf, *ngFor, ngClass, ngStyle
- Pipes: Built-in and Custom
- Template-driven Forms

### 🛠️ Projects:
- Task Tracker App
- Simple Calculator
- Contact Form with Validation

---

## 📙 Phase 2: Intermediate Concepts (Week 3–4)

### 🎯 Goal:
Master API communication, navigation, and basic RxJS usage.

### ✅ Topics:
- Reactive Forms (FormGroup, FormBuilder)
- Services & Dependency Injection
- Routing & Navigation (Route Params, Guards)
- HttpClientModule for REST APIs
- RxJS Operators: map, filter, debounceTime, etc.

### 🛠️ Projects:
- Blog App with Routing and API
- Employee Directory with Search
- Weather App with RxJS and HTTP

---

## 📕 Phase 3: Advanced Angular (Week 5–7)

### 🎯 Goal:
Build scalable, reusable, and high-performing Angular apps.

### ✅ Topics:
- Angular Signals (v16+)
- Change Detection & OnPush Strategy
- Content Projection with ng-content
- Lazy Loading Modules
- Smart vs Dumb Components
- Standalone Components (v14+)
- Advanced RxJS (switchMap, mergeMap)

### 🛠️ Projects:
- Real-Time Search App
- Modular E-Commerce Listing
- Lazy Loaded Dashboard

---

## 📗 Phase 4: Enterprise Skills (Week 8–10)

### 🎯 Goal:
Apply enterprise-level design patterns, testing, SSR, and i18n.

### ✅ Topics:
- State Management (NgRx, SignalStore, Akita)
- Unit Testing (Jasmine, Karma)
- Angular Universal (SSR)
- Progressive Web Apps (PWA)
- Internationalization (i18n)
- Accessibility (ARIA)
- CI/CD, Environment Configs

### 🛠️ Capstone Projects:
- SaaS Admin Dashboard
- PWA-based Expense Tracker
- Universal Blog with SSR

---

## 🧪 Optional Enhancements (Post Week 10)

- Nx Monorepo Setup
- Micro Frontends with Module Federation
- Ionic + Angular Hybrid App
- Backend Integration (Spring Boot, Node.js)
